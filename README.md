# larambladepto

Guía bilingüe (ES/EN) con mapa interactivo para huéspedes. Sitio estático, sin build.

- `js/places.js`: todos los lugares y textos. Para ubicar uno, agregá `ll: [lat, lng]`.
- `img/places/<id>.jpg`: foto de cada lugar (si falta, se ve un cuadro de color).
- Probar local: `python3 -m http.server 8123`
- Publicar: GitHub Pages (Settings > Pages > rama `main`, carpeta `/`).
